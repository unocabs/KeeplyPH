# Car brand icons — 69 brands

Collected on October 4, 2026, for the brand list in this conversation.

- `png/`: one transparent 512 × 512 PNG icon per brand, with consistent canvas size and preserved source colors.
- `originals/`: selected SVG or PNG source files. Aito and DFSK SVG files have only their explicit full-canvas white background path removed, as recorded in the manifest.
- `preview.png`: labeled contact sheet on a checkerboard to make transparency visible. The checkerboard is not part of any individual icon.
- `sources.csv`: per-brand download links, sources, and preparation notes.
- `manifest.json`: per-brand file mapping and PNG validation results.
- `licenses/`: available license notices from source collections.

## Checks and limits

All 69 final PNG files were decoded and checked for 512 × 512 dimensions, visible artwork, and fully transparent pixels. The contact sheet was visually reviewed. SVG artwork is rendered at sufficient resolution before PNG export. Source colors and artwork are preserved, including intentional white details inside emblems.

This is a collected reference set, not a set of official brand guidelines. Sources contain mixed logo editions, including legacy variants for some brands (for example GWM, Mahindra, Chery, Changan, MINI, Volvo, and Fiat). The latest Philippine-market identity has not been verified for every logo. Raster sources have their original detail limits; a 512px export does not add detail to a small raster source. Some brands use a wordmark instead of a separate emblem.

The source collections are vehiclespecs/brand-logos, filippofilip95/car-logos-dataset (sourced from Carlogos.org), cardog-ai/icons, Wikimedia Commons, China EV Pro, and SuperDevPro. Exact source URLs appear in sources.csv. Collection licenses do not transfer ownership of the trademarks; brand logos remain the property of their owners.
